Rather than testing all numbers up to the desired bound using Corollary 3.3, we wrote a sieve that first divided by small primes. Note that if 𝜔=𝜔⁡(𝑞) is the order of 10 modulo a prime q, then 𝐵𝑑⁡(𝑛+𝑘⁢𝜔,𝑚) is congruent to 𝐵𝑑⁡(𝑛,𝑚) modulo q. Thus, if q is a divisor of 𝐵𝑑⁡(𝑛,𝑚), then it is also a divisor of 𝐵𝑑⁡(𝑛+𝑘⁢𝜔,𝑚) for 𝑘=0,1,2,…. This result allows us to discard many values of n before testing. Further, if a prime q divides 𝐵𝑑⁡(𝑛,𝑚), then it must be the case that the Legendre symbol (𝑑2−4⁢(10𝑚−1) ∣ 𝑞) is not −1. The values that made it past this sieve were tested using Maple’s isprime function, at which point we had a list of probable primes. These values were then proved prime using Corollary 3.3 or by trial division in the event that 𝑛<3.
